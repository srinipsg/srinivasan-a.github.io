How to add a new project video

1. Upload the video to YouTube/Vimeo. 2. Copy its embed URL. 3. Open project-outcomes.html. 4. Duplicate a video card and replace the iframe URL, title, category and description. 5. Commit the file to GitHub. The website will update automatically.
